# Node.js 与 npm

Source: https://bot.fmcat.top/tools/nodejs

> 本页介绍在 Grok Bot 云电脑中配置 Node.js 与 npm 基础环境的方法。复制给定的提示词发给助手通过管理脚本部署，无需任何账号授权，即可为各类现代命令行工具提供运行支撑。

Node.js 与 npm 是前端及各类 AI CLI 的执行基础，适合为 Bot 提供 现代命令行工具的运行环境 。

## 发给 Bot 的提示词

复制下方整段内容发送给你的 Grok Bot，它会在云电脑上自动安装并验证，遇到登录或配置密钥时会暂停等待你操作。

```
帮我在你的云电脑上安装好 Node.js 与 npm（https://github.com/nvm-sh/nvm），以后运行前端项目和各类命令行工具用它。
```

## 需要你自己做的事

- 确认云电脑网络连通，无需准备外部账号。
