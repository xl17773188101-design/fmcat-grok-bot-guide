# Gemini CLI

Source: https://bot.fmcat.top/tools/gemini-cli

> 本篇提供在 Grok Bot 云电脑上配置 Gemini CLI 的操作指南。复制文中的提示词让助理安装该终端工具，通过浏览器打开验证链接绑定谷歌账号，即可展开终端交互与日常开发协作。

Google 开源的终端 AI Agent，适合 付费用户与 Google Cloud 项目用户 进行终端交互与开发协作。

## 发给 Bot 的提示词

复制下方整段内容发送给你的 Grok Bot，它会在云电脑上自动安装并验证，遇到登录或配置密钥时会暂停等待你操作。

```
帮我在你的云电脑上安装 Gemini CLI（https://geminicli.com/docs/get-started/installation/），以后终端交互和开发协作用它。需要登录或授权时停下来把链接发给我由我完成。
```

## 需要你自己做的事

- 准备付费 Google 账号或 Google Cloud 项目账号。
- 在浏览器打开 Bot 发送的授权链接完成认证。
