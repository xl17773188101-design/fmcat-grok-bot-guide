# agently-cli（Agent 邮箱命令行）

Source: https://bot.fmcat.top/tools/agently-cli

> 介绍为 Grok Bot 接入 agently-cli 邮件命令行的方法。向助手发送说明中的提示词以在云电脑部署工具，在浏览器打开授权链接完成账号绑定，即可实现邮件收发与附件管理功能。

腾讯 QQ 邮箱推出的官方命令行工具，适合让 Bot 在 云电脑 上收发邮件、检索历史邮件并下载附件。 Bot 在云电脑中收发邮件、检索历史并下载附件。

## 发给 Bot 的提示词

复制下方整段内容发送给你的 Grok Bot，它会在云电脑上自动安装并验证，遇到登录或配置密钥时会暂停等待你操作。

```
帮我在你的云电脑上安装 agently-cli（https://agent.qq.com），以后收发邮件、检索历史邮件和下载附件用它。需要登录或授权时停下来把链接发给我由我完成。
```

## 需要你自己做的事

- 准备 QQ 邮箱或 Agent 邮箱账号。
- 打开 Bot 发送的授权链接在浏览器中完成验证。
