# MCP 连接器

Source: https://bot.fmcat.top/tools/mcp-connectors

> 介绍如何在 Grok Bot 体系下启用 MCP 连接器并与云电脑协同。依照页面提示词让助手搭建连接配置，读者自行在管理页面授权第三方账号或填入密钥，即可直接调用外部工具与数据资源。

MCP 连接器打通了外部服务与模型的交互通道，适合让 Bot 直接调用外部工具与云端数据 完成复杂协同。

## 发给 Bot 的提示词

复制下方整段内容发送给你的 Grok Bot，它会在云电脑上自动安装并验证，遇到登录或配置密钥时会暂停等待你操作。

```
帮我在你的云电脑上接入 MCP 连接器（https://docs.x.ai/grok/connectors），以后调用外部工具和同步云端数据用它。需要第三方授权时把链接发给我，需要填密钥时请提醒我自己填。
```

## 需要你自己做的事

- 在浏览器访问连接器控制页面并准备待连接账号。
- 根据提示自行填入目标服务的地址或授权密钥。
