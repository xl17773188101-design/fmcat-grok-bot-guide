# Cursor CLI

Source: https://bot.fmcat.top/tools/cursor-cli

> 讲解为 Grok Bot 所在的云电脑安装配置 Cursor CLI 的流程。利用文章准备好的提示词吩咐助理完成命令行端配置，并在接收到认证链接后完成授权，适合分担小范围代码修改等细化工作。

Cursor 官方命令行 Agent，适合 在云电脑执行小范围代码修改 ，将 Bot 额度留给全局决策。

## 发给 Bot 的提示词

复制下方整段内容发送给你的 Grok Bot，它会在云电脑上自动安装并验证，遇到登录或配置密钥时会暂停等待你操作。

```
帮我在你的云电脑上装好 Cursor CLI（https://cursor.com/docs/cli/installation），以后小范围代码修改用它。需要登录或授权时停下来把链接发给我由我完成。
```

## 需要你自己做的事

- 准备 Cursor 账号或相关授权凭证。
- 在浏览器打开 Bot 发送的授权链接完成登录。
