# Claude Code

Source: https://bot.fmcat.top/tools/claude-code

> 面向 Grok Bot 用户介绍 Claude Code 在云电脑上的接入方式。将页面提示词发送给助理协助完成工具准备，在需要身份验证时打开链接确认，即可借助该工具处理复杂代码库阅读与修改任务。

Anthropic 官方终端编码 Agent，适合 代码库阅读、多文件修改与命令执行 ，支持后台自动更新。

## 发给 Bot 的提示词

复制下方整段内容发送给你的 Grok Bot，它会在云电脑上自动安装并验证，遇到登录或配置密钥时会暂停等待你操作。

```
帮我在你的云电脑上装好 Claude Code（https://code.claude.com/docs/en/setup），以后阅读代码库和多文件修改用它。需要登录或授权时停下来把链接发给我由我完成。
```

## 需要你自己做的事

- 准备 Claude 订阅或 Anthropic Console 账号。
- 在浏览器打开 Bot 发送的授权链接完成认证。
