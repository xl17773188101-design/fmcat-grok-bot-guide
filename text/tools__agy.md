# Antigravity CLI（agy）

Source: https://bot.fmcat.top/tools/agy

> 本教程介绍如何在 Grok Bot 的云电脑中配置 Antigravity CLI 工具。读者只需复制提供的提示词发送给助理，并在收到授权链接后完成登录，即可利用该工具开展视频理解、长文本与代码处理任务。

Google 官方终端 Agent，适合 视频理解、长文写作与代码修改 ，支持直接读取视频文件。

## 发给 Bot 的提示词

复制下方整段内容发送给你的 Grok Bot，它会在云电脑上自动安装并验证，遇到登录或配置密钥时会暂停等待你操作。

```
帮我在你的云电脑上安装配置 Antigravity CLI（https://antigravity.google/docs/getting-started/），以后视频理解、长文写作与代码修改用它。需要登录或授权时停下来把链接发给我由我完成。
```

## 需要你自己做的事

- 准备 Google 账号。
- 在浏览器打开 Bot 发送的授权链接完成认证。
