# Codex CLI

Source: https://bot.fmcat.top/tools/codex

> 介绍在 Grok Bot 专属云电脑中部署 Codex CLI 的方法。读者直接复制说明中的提示词发给助手，在浏览器打开返回的链接完成设备码授权，便能使用现有账户额度进行代码编写与脚本调试。

OpenAI 官方终端编码 Agent，适合 代码修改、脚本运行与生图审图 ，可直接使用 ChatGPT 订阅额度。 适合需要修改代码、执行脚本与生图审图的 ChatGPT 订阅用户。

## 发给 Bot 的提示词

复制下方整段内容发送给你的 Grok Bot，它会在云电脑上自动安装并验证，遇到登录或配置密钥时会暂停等待你操作。

```
帮我在你的云电脑上装好 Codex CLI（https://developers.openai.com/codex/cli），用我的 ChatGPT 账号登录，以后写代码、跑脚本和生图用它。需要我授权时把链接发给我。
```

## 需要你自己做的事

- 准备 ChatGPT 账号并确认开启设备码登录权限。
- 在浏览器打开 Bot 发送的设备码链接完成确认。
