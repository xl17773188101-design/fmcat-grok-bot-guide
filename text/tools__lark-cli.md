# 飞书 CLI（lark-cli）

Source: https://bot.fmcat.top/tools/lark-cli

> 解析在 Grok Bot 云电脑中配置飞书 CLI 的具体流程。复制文中的提示词发给助手安装命令行工具，在收到授权地址后打开网页输入验证码，即可协同管理云文档与多维表格。

飞书官方命令行工具，适合让 Bot 以个人身份在 云电脑 上操作飞书云文档、多维表格、云盘和知识库。 Bot 以个人身份在云电脑中操作飞书云文档、多维表格、云盘与知识库。

## 发给 Bot 的提示词

复制下方整段内容发送给你的 Grok Bot，它会在云电脑上自动安装并验证，遇到登录或配置密钥时会暂停等待你操作。

```
帮我在你的云电脑上安装配置飞书 CLI（https://github.com/larksuite/cli），以后操作飞书云文档、多维表格和云盘用它。需要登录或授权时停下来把链接发给我由我完成。
```

## 需要你自己做的事

- 准备飞书个人账号。
- 打开验证链接输入终端给出的设备码确认授权。
