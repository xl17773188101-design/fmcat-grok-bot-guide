      PCv0.75.5

      新增保险库与邮件转发功能

      • 设置新增保险库，Bot 可保存并自动填写登录与支付信息
      • 优化自动审核机制，明确指令不再频繁弹出二次确认卡片
      • Bot 支持完整保留原排版、图片与附件转发收件箱邮件
      • 自动化任务频次上限提升，每小时最高可运行 300 次
      查看完整中文翻译

      新功能

      • Bot 可以将您的登录信息、银行卡和联系信息保存到「Settings」中的「Vault」，并在登录或结账时自动填充。需要 Grok Bot 0.75.2 或更高版本。
      • Bot 可以从其自身的收件箱转发电子邮件，并保留原始格式、图片和附件。需要 Grok Bot 0.75.2 或更高版本。
      • Bot 会记录其在 Slack 中发布的每条消息是由谁请求的，因此 thread 中的任何人都可以询问是谁请求发送的。
      • 适逢万圣节，您可以在创建 Bot 或更换其头像时选择南瓜造型。需要 Grok Bot 0.75.2 或更高版本。

      改进

      • 对于您用自己的话明确要求的操作，Auto-review 询问确认的频率降低了。
      • 在您拒绝审批卡片后，Bot 会停止操作，且在您发送下一条消息之前不会再次尝试该操作。
      • 您要求 Bot 发送的电子邮件和 Slack 消息在 Auto-review 批准后即可发出，而触发器及其他轮次中的发送操作仍会作为草稿留存等待。
      • 当 Bot 将 Bot 的电脑交由您操作以登录支持连接器的网站时，它还会提供该连接器的连接卡片。
      • 向 Bot 询问您的 X 账号时，即使您已移除了 X 插件，也会通过已关联的 X 账号连接 X。
      • 连接 X 会通过同一账号同时连接 X Money；询问关于您的 X Money 余额、动态或卡片时，会自动安装 X Money。
      • 您的触发器每小时总计运行次数上限从 100 次提升至 300 次，且单个触发器最高可运行 200 次。
      • 在开启「Route traffic through this computer」时，「Settings」会显示有多少个网站因解析至私有或 VPN 地址而被拦截。
      • 团队成员在与团队 Bot 的单独私聊中，可以对消息添加表情回应、使用「Add to chat」引用消息以及回复卡片。(Teams)
      • 团队 Bot 在请求使用某个连接器或说明使用了谁的连接器时，会显示与您的插件列表一致的连接器名称（例如 Google Slides）。(Teams)
      • 如果您的 Grok Business 席位尚未涵盖 Grok Bot，用量超限提示会引导您联系 Grok Business 管理员以连接您的团队。

      修复

      • Auto-review 回退至审批卡片的频率降低，并在检查失败时自动重试，对于长对话会继续审核而不是直接停止。
      • Auto-review 不再放行您在请求中要求在此前停止的操作，例如在您明确只要求起草消息时却将其发送。
      • 向 Bot 询问您的 X 关注者时，会直接收到 X 不提供该信息的明确回答，而不再引导通过浏览器登录 X。
      • 账号合并后，您仍可继续管理自己创建的 Bot，并能将其共享给团队。
      • 包含多个服务器的插件（例如 Salesforce）会将每个服务器单独显示为一行，方便您查看并登录每一个服务器。
      • 在 Slack 中，Bot 会像对待其他 thread 回复一样，正常回复同时发送至频道的 thread 回复。
      • 在团队 Bot 的「Share this Bot」卡片上，通过群组管理该 Bot 的成员其角色会显示为「Manager」。(Teams)
      • 团队 Bot 在共享聊天中交接的工作可以使用您已允许的连接器，且其回复会注明使用了谁的连接器。(Teams)
      • 当团队 Bot 的触发器在 Slack thread 中回复后，Bot 会持续关注该 thread，无需 @提及 即可直接回答后续回复。(Teams)
      • 在重置首条消息被拦截的会话后，发送新消息能够正常获得回复，而不再报错。

      新功能

      • Bot 可以构建 Pages（例如报告、备忘录和仪表盘），支持与你协同编辑，或由 Bot 保持内容最新。
      • Bot 可以根据文字描述或你分享的图片生成视频。
      • 你可以将「Library」中的页面、文件和链接固定到置顶的「Pinned」分区，并在你的各设备间保持同步。
      • 仪表盘的「Pages」分区会列出你已分享的 Pages，你可以在此取消分享或删除它们。
      • 将鼠标悬停或聚焦在「Library」列表项上，即可预览发送者、发送时间以及谁可以查看该 Page。
      • Bot 支持使用 Shop Pay 进行支付：在支持的商店中通过 Shop 结账，在其他商店则使用一次性 Shop 卡。
      • 你可以从聊天、连接器页面或结账界面一键连接 X Money（若尚未关联 X 账号，需先登录 X）。
      • Page 所有者可以将 Page 分享给整个组织或组织内的其他团队。(Teams)
      • 团队管理员可以限制谁能与团队中的全员分享 Pages。(Teams)
      • 团队管理员可以开启链接预览功能，在任何发布团队 Bot 链接的地方显示其名称、描述、颜色和形状。(Teams)
      • 可以通过 ⌘/ 以及从「Help」、个人资料菜单和命令面板打开快捷键面板。
      • 在输入框行首输入 > 即可开启块引用，在引用行行首按 Backspace 即可退出引用。
      • 你可以在输入框中通过拖拽附件或按住 Alt 搭配方向键来调整其顺序。
      • 你可以连接 Zoho CRM，并在登录前选择你账号所在的区域数据中心。
      • 团队管理员可以上传团队图标，该图标会显示在工作区选择器和团队 Bot 上。(Teams)
      • 团队 Bot 所有者和管理员可以允许协作者在「Configure」中创建触发器。(Teams)
      • Pages 支持捕获鼠标指针并全屏显示。
      • GitHub 连接器可以列出你的代码仓库、对比提交、列出 Pull Request 的提交记录，并读取分支与 Issue 评论。
      • 内置 Gmail 连接支持在草稿和发送时添加附件、全部回复、转发时添加附言，以及设置标签颜色。
      • Bot 可以单步批量创建、更新或删除多个 Google Calendar 日程，且编辑后的日程不会再发生时间偏移。
      • 触发器可以读取 Bot 的收件箱。
      • 由 Bot 转交的任务可以为聊天生成图片和视频。
      • 在团队或群聊中，共享团队 Bot 的欢迎消息包含「Chat with me」链接，而仅所有者专用的 Bot 只会向其所有者发送问候。(Teams)
      • 企业团队管理员可以在「Security & Compliance」中的「Manage Member Computers and Data」处，或通过 Admin API 永久删除成员的 Grok Bot 数据。(Enterprise)

      改进

      • 聊天中的卡片采用全新设计，涵盖从审批卡片、提问卡片到文件、链接与表格等各类卡片。
      • Bot 详情面板采用单列布局，点击即可编辑的个人资料位于「Media」、「Computer」和「Routines」标签页上方。
      • 语音通话现可参考你早前的通话记录以及近期与 Bot 的聊天内容。
      • Bot 在发送链接前会先打开验证，并自动排除失效链接。
      • Auto-review 审批卡片会用一句话说明操作内容，标明对应应用名称与图标，并标记不可逆或敏感的更改。
      • 当你提及某项服务时，Bot 会在首条回复中显示该连接器的连接卡片。
      • 当连接器将你退出登录或拒绝登录时，Bot 会说明具体原因（例如 Google 账号受限）以及解决方法。
      • 当触发器遇到已退出登录的连接器时，聊天界面会显示该连接器的「Reconnect」卡片，每天最多显示一次。
      • 在执行需要耗时数分钟的浏览器或桌面任务之前，Bot 会提前提示你该任务需要一些时间。
      • 如果你已在聊天中提供了密码或验证码，Bot 会直接使用，而不会拒绝继续执行。
      • 回复中提及的 Pull request、Issue 和代码仓库均会显示为链接。
      • 当 Bot 询问付款方式时，你可以直接在卡片上进行选择。
      • 个人 Bot 在某次聊天中保存到记忆的内容，会在你与它的所有聊天中保持记忆，且仅有你能对其进行修改。
      • 删除 Bot 将永久抹除其对话、记忆、触发器与附件，并移除其 Slack 应用。
      • Bot 向新联系人发送的第一封邮件会包含一键退订链接。
      • 在 Slack 中，让 Bot 去调查、调研或核实某些内容时，会获得经过深入调研的回答，而不是简短的快速回复。
      • 删除账号前会先列出你将失去的内容；关联已统一的 Grok 账号时会提供合并选项，而不是直接报错失败。
      • 回复中的来源链接会显示为紧凑的引用标签，公司名称则显示为股票代码胶囊标签。
      • 聊天表格中的数字列现按小数点对齐，并支持表头副标题、汇总行与脚注。
      • 你发送的文件会以卡片形式显示其类型、名称和大小；鼠标悬停在附带说明文字的图片上时会提供「Copy」和「Download」选项。
      • 点击表情回应时会即时显示，且消息不会再在鼠标指针下方发生位移。
      • 对于拥有较多团队 Bot 的用户，「Library」的打开速度更快。
      • 与你共享的团队 Bot 会直接打开其已保存的对话。(Teams)
      • 浏览器登录最多等待 20 分钟并提供「Copy link」选项，点击「Reopen link」可继续当前登录流程而无需从头开始。
      • 「Connect Apps」中会显示每个插件自身的图标；使用自己的 OAuth 客户端配置插件时，会列出需要注册的回调 URL。
      • Webhook 触发器的菜单会显示其 URL 和密钥，且密钥会一直保持隐藏，直到你主动点击显示。

      修复

      • 在长对话中快速向上回滚时，不再会在加载更早消息前出现卡顿。
      • 更早聊天记录中的搜索结果现已能准确定位至对应消息，即使在应用刚启动时也是如此。
      • 桌面通知现将 Bot 回复显示为包含完整链接的纯文本，并会跳过你在其他设备上已读的回复。
      • 语音通话在网络中断和崩溃后能够自动恢复，麦克风重连时会自动重新拾音，且在你静音时 Bot 仍可作答。
      • 录制语音留言时，按一次 Enter 键即可发送。
      • Page 打开时，包括 ⌘F 和命令面板在内的快捷键均可正常使用，且打开命令面板不再会关闭 Page。
      • Page 打开时按「Back」会关闭该 Page 并停留在当前 Bot，而不是跳转到之前浏览过的 Bot。
      • Page 的「Share」菜单会显示其当前的可见性状态，即使该状态已在其他设备或控制台中更改。
      • 当消息无法保存时，应用会提示是否是因为你的电脑磁盘空间不足。
      • 桌面应用现默认直连，除非已开启系统代理，这修复了在部分企业代理网络下的加载问题。
      • 登录无法连接时，应用会提示你检查网络连接，而不是提示已停止等待浏览器响应。
      • 全新安装或重新安装的桌面应用会自动为已完成新手引导的账号跳过该引导。
      • 输入追问内容会使未处理的提问卡片保持未作答状态，而不是直接将其作为回答。
      • 在回复中通过 @ 提及的 Bot 名称可点击打开该 Bot 的聊天界面。
      • 开启或关闭 Bot 的工具时会应用你当时看到的状态，避免因列表数据过时而重新开启已被禁用的工具。
      • 创建 Bot 或发布 Bot 模板被拒绝时，应用会显示具体原因。
      • Bot 重命名 Page 后，Page 卡片和标题会立即更新，历史 Page 卡片也会直接打开其最新版本。
      • 「Connect Apps」会为插件预留更长的等待时间，而不是直接显示「Couldn't refresh」；内置插件也不再会提供无法生效的「Uninstall」选项。
      • 在桌面应用中购买额度、开启自动充值以及保存支出限额时，均会显示确认或错误提示。
      • 在 Bot 工作期间添加的表情回应和卡片回答，在其轮次结束后仍会保留。
      • 未及时处理的审批会在聊天中留有一行提示，说明具体过期的内容。
      • 对 Google Slides 的大规模编辑现可实时同步更新到在线演示文稿中。
      • Bot 通过 Gmail 发送的邮件会显示你的姓名以及为该邮箱地址保存的签名，且回复草稿会保留在对应的会话中。
      • 大于约 3 MB 的 Bot 图片现在可以正常保存。
      • 即使你在 Bot 完成交接前发送了消息，触发器的运行结果仍会正常送达给你。
      • 暂停和恢复触发器时会保留你的最后一次选择，即使从两台设备进行操作也是如此。
      • 账号合并后，保留的账号将继续保留其 Grok Bot 邮箱收件箱和连接器设置。

      新功能

      • Bot 可以使用带标签格式的自身电子邮箱地址（例如 name+shop@）发送邮件，且该标签上的触发器仅针对其邮件运行。
      • Bot 要求你填写的表单可以预先填好已知字段，你可以在提交前进行编辑。
      • 在付费账户合并仍在迁移该账户的数据时，「Settings」会显示「Your accounts are being merged」，若耗时过长还会显示「Contact Support」。
      • 团队管理员可在控制面板的「Bot capabilities」下关闭「Messaging between Bots」，使团队成员的 Bot 无法向其他 Bot 发送消息或移交工作。（Teams）
      • 企业团队管理员可在控制面板的「Manage Bot Computers」中或通过 Admin API 重新创建、终止或删除成员的 Grok Bot 的电脑。（Enterprise）
      • 当 Bot 的电脑磁盘空间不足时，Bot 会提醒你一次并列出占用空间最大的文件，仅在你同意后才会将其删除。

      改进

      • 当你在 Mac 或 Windows 电脑上使用 Grok Bot 时，Bot 的回复和提问会在电脑端通知你，而不是手机端。需要 Grok Bot 0.70.2 或更高版本。
      • 你可以附加最大 250 MB 的文件和最大 1 GB 的视频；若视频过大无法观看，Bot 会进行提示。需要 Grok Bot 0.70.2 或更高版本。
