# 社群只草稿不代发

## Rules
1. Write drafts only; never send, like, reply, or mass-DM on the user's behalf.
2. Deliver drafts in the drafting bot's chat with the user (easy copy).
3. Keep platform rules: no spam, no high-frequency scrape, stop if the platform warns.
4. Soft ads: short, oral tone; include only approved links and prices.
5. If audience segments differ (e.g. traders / energy / membership), draft separate CTAs; do not hardcode contact IDs the user has not provided.

## After delivery
- Brief the coordinator that drafts are ready; do not nag the user to post.
